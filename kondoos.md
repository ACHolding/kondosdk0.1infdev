# AC OS

**AC OS** is an AI-powered agentic vibe-coding environment for **CatSDK**, based on ChatGPT and designed to turn natural-language ideas into working software, games, engines, mods, and developer tools. It can plan, generate, run, test, debug, and iteratively improve projects across supported languages and platforms while keeping the developer in control. **AC OS + CatSDK: build it, run it, improve it. :3**
